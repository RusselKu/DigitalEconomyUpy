# Validated Indicator Extracts

This directory contains small, documented extracts used when a project indicator requires an explicitly validated comparison set.

## WIPO Resident Patent Applications per Million Population

File: `wipo_patents_2023.csv`

Indicator: Resident patent applications per million population  
Reference year: 2023  
Economies: Argentina, Kenya, Mexico, Netherlands, New Zealand

Values used:

- Argentina: 9
- Kenya: 7
- Mexico: 8
- Netherlands: 495
- New Zealand: 60

Primary statistical source:
WIPO IP Statistics Data Center  
https://www3.wipo.int/ipstats/

Cross-country verification:
German Federal Statistical Office international statistics, sourced to the WIPO Statistics Database.

Verification note:
WIPO World Intellectual Property Indicators 2024, Figure A38, reports 495 resident patent applications per million population for the Netherlands in 2023. This matches the value used in the project.

No imputation is applied to this indicator.
