# Presentation Script · Jonathan

Suggested duration: 3–4 minutes. This script supports the documents; it does not report results from a completed pilot.

## 1. Diagnosis and the 4Cs

My contribution connects the digital diagnosis with a precision irrigation proposal. Mexico ranks fourth in the repository DRS, but the result depends on completing dataset traceability. National indicators cannot directly describe an individual farm.

Across the 4Cs, connectivity requires coverage tests and outage planning; compute requires workload sizing; context requires soil, crop and water data; and competency requires training producers, technicians and agronomists. INEGI reported a 19.5 percentage point gap between urban and rural internet use in 2023. This identifies a gap, although it does not measure connectivity on a particular farm.

## 2. Business Model

We propose starting with avocado producers or associations with managed irrigation. We create value through irrigation recommendations, deliver it through sensors, an application and support, and capture it through subscriptions and node sales. USD 12 per hectare per month and USD 180 per node are assumptions to validate. The 25% water reduction is an experimental target.

## 3. Platform and Scalability

The first stage is a software service. A second stage would connect producers with suppliers and technicians for quotations and contracting. More producers could attract suppliers, and better options could attract producers: these are proposed indirect network effects.

Moving from 10,000 to 100,000 nodes increases monthly readings from 28.8 million to 288 million. Data volume and processing work grow approximately tenfold. We can share fixed costs, but we still pay for cloud services, maintenance and field support.

## Likely Questions

- **Why AI?** It should outperform an agronomic baseline out of sample; a complex model is not required from day one.
- **Do secure servers measure GPU capacity?** No. The indicator counts TLS/SSL certificates.
- **Do more data always improve the model?** No; records must be accurate, comparable and relevant to the crop and soil.
- **Is this already a two-sided platform?** It is a proposed stage requiring actual interaction between both sides.
- **Is it already profitable?** This has not been demonstrated; quotations, willingness-to-pay evidence and a pilot are needed.
- **What is needed to verify the diagnosis?** Original sources and reference years for ITU, UNCTAD, WIPO and R&D must be completed with the dataset owners.
